# Spot the Ball Game

A fun interactive game where players guess the correct ball position by selecting option 1, 2, or 3.

## Setup

1. Make sure all your question and answer images are in the `Pics/` folder
2. Open `answers.js` and update the `correctAnswers` array with the correct option (1, 2, or 3) for each question
3. Open `index.html` in a web browser to play!

## How to Play

1. View the question image
2. Click on option 1, 2, or 3
3. See if you're correct or wrong
4. View the answer image
5. Click "Next Question" to continue

## File Structure

- `index.html` - Main HTML file
- `style.css` - Styling
- `script.js` - Game logic
- `answers.js` - Configuration file with correct answers (update this!)
- `Pics/` - Folder containing question and answer images

## Updating Correct Answers

Edit `answers.js` and change the numbers in the `correctAnswers` array. Each number should be 1, 2, or 3 representing the correct option for that question.
